## 人的方向與責任

使用者指定以臺灣前端／網頁工程師求職為目標，優先呈現已有的工程成果，保留 V3 互動世界、中英文及無障礙體驗。公開來源限制、案例順序、不可誇大測試與部署狀態、沿用既有免費測試站，均來自本次已授權的任務範圍。

是否宣稱已親自理解、手寫或人工驗收，仍須有對應紀錄；本次不代為認定。敘事重心不轉成程式碼、工時或貢獻度百分比。

## Codex 的實作與查證工作

- AssetFlow：確認當下為 Public，核對 Vue 表單、Pinia、領還／交接服務、日期契約、公開測試與 CI，整理操作步驟、來源截圖與雙語案例。
- BookFlow：確認當下為 Public，核對 React 表單、booking service、tenant lock、冪等與排程測試、公開 PR 與 CI，整理工程挑戰與限制。
- 作品集：實作直接導航、技能與證據索引、媒體標示，執行本次變更的公開審查及集中檢查；部署與線上驗收結果另以實際交付紀錄為準。
