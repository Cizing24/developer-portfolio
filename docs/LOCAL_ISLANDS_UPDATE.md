# 七島場景本機更新

此輪依 2026-10-28 的八項需求實作。本文件記錄提交前的本機驗證；遠端 CI、PR 合併與部署結果，另以對應 GitHub 與 Cloudflare 紀錄核對。

## 場景與操作

- 時段、底部工具列及選單按鈕清除全站內距，SVG 固定尺寸並置中；播放與暫停兩種圖案皆驗證。
- 功能島共七座。在隆昌有獨立港口，未加入五條主島陸橋的拓樸。
- 桌機與直向版面共用可通行範圍、建築／樹木／燈柱碰撞資料。橋梁模型與導航使用同一份落點定義，避免視覺橋與路徑分離。
- 小人與 CIZING 使用依半徑建立的地面路徑圖，逐段檢查路線；人物之間以掃掠圓避讓。窄路阻塞時等待及重新選擇方向，不透過其他人物。
- 船隻使用獨立水域圖，避開功能島與裝飾礁島，並往返在隆昌港口。人物不會用水域路線跨越獨立島。
- 移動物件使用每次繪製都更新的即時投影陰影；靜態建築保留快取陰影。此為適合低多邊形場景的接地陰影，不是逐三角形即時光線追蹤。
- 海面為有限圓形區域，周圍 38 座邊界島加上 6 座礁島，使用 instancing 控制繪製成本。
- 保留暫停、減少動態效果、WebGL fallback、中英文 URL 與閱覽室導覽。

- 產品介面使用 CIZING；GitHub 的真實網址保留原帳號。
- 個人介紹補上開發方向、處理問題的方法、學習與 AI 協作界線，不新增未經證實的任職經歷或成果。
- 在隆昌筆記依當前網站原始碼與 README 核對發布條件、授權與公開圖片概念；公開入口為 https://zailongchang.tw/ 。不公開私人原始碼或內部基礎設施。
- 棉麻屋筆記依現有專案文件與服務流程整理，限工程摘要；不加入客戶資料、精確營運規則、內部端點、第三方帳號、私人程式碼或展示網址。
- 政府計畫僅納入使用者個人的「青年村落文化行動計畫」。依 Notion 2026-10-16 送件紀錄與本次使用者範圍標示申請中，沒有新增核定、獲選、執行完成或補助額宣稱。未公開原始附件、簽名及預算。
- 三篇新筆記都有完整中英文版本與獨立分類；筆記島的實體面積與閱覽室分類同步擴充。

## 驗證範圍

導航測試涵蓋桌機／直向版面的主島連通性、CIZING 大半徑路徑、獨立島無陸路、港口水路、連續碰撞與多人避讓。瀏覽器測試涵蓋四種尺寸的按鈕對齊、兩語新內容、個人介紹、自動移動、港口及暫停陰影。

本機畫面與測試結果須以實際執行紀錄為準；本文件不把先前 CI 或既有網站上線狀態當成本輪遠端驗證。

## 本次實際結果

- 47 項單元測試通過，涵蓋導航、碰撞與原有內容契約。
- Lint、TypeScript、Astro check、內容翻譯契約、格式檢查、Build 與 SEO 檢查通過。
- 首次完整瀏覽器回歸：116 項中 112 項通過，4 項失敗。兩項為移動角色的閱讀入口持續變動，兩項為旋轉後測試手勢落在島名標籤。修正閱讀入口的位置，並讓手勢測試先核對整段路徑確實位於 Canvas；原有一指／雙指旋轉斷言保留。
- 修正後針對四種尺寸重跑 28 項相關測試，全數通過，包含相機／閱讀、手勢、人物尋找、短螢幕、入口不重疊、港口及陰影。
- 合併每個測試情境的最新結果，共涵蓋 116 項，沒有未解決失敗。這不是宣稱修正後又完整重跑一次 116 項。可核對 [驗證摘要](evidence/islands-update/validation.json)。

## 橋面接合與人群通行追加修正

依瀏覽器標註，BookFlow 與 AssetFlow 的橋面轉折改成共用斜接邊界，兩側欄杆沿完整輪廓連接。橋面模型與人物通行範圍使用同一份多邊形；岸邊保留足夠重疊，路段採樣加密，避免較大人物在接岸處反覆轉向。

人物受阻後從實際位置重新接上路徑，將附近人物當作臨時障礙繞行；無法通過時短暫退讓。日常目的地以原島散步為主，保留跨島行程，降低所有人頻繁通過主島的集中流量。

追加回歸涵蓋兩種版面的橋面轉角、六人對向通行，以及 26 人一分鐘模擬；同時驗證無重疊與最後 20 秒每個人物持續有移動進展。追加修正之後的遠端 CI 需以最新提交結果為準。
