# V3 互動群島

2026-10-23，Asia/Taipei。現行首頁是完整場景，所有主要文字內容以同頁閱讀框開啟。

## 島嶼與內容

六座島分別為作品集、BookFlow、AssetFlow、筆記、聯絡與 Cizing24。島嶼有各自的模型、固定位置與小型標籤，以橋樑連接。桌面與手機橫向使用寬版配置，直向螢幕使用雙欄配置；切換島嶼只移動相機，不替換整個模型。

`world-config.ts` 定義島嶼、中英文名稱、內容入口與四個時段。新增入口應先更新這個共同來源，再處理場景模型，避免清單和模型連到不同內容。

兩座專案島提供目的、作用、架構三個入口。`project-introductions.ts` 與 `ProjectIntroduction.astro` 共用簡明產品介紹，MDX 保留圖片與公開來源邊界；深入工程內容留在筆記。

主畫面不放品牌標語、長篇介紹、版本旁註或重複的功能說明。透明頁首只放標題、語言與時段；底部圖示提供全景、縮放、動態、尋找個人角色與操作說明。右側抽屜可搜尋島名或內容標題，選島移動視角並展開細節。長文透過同頁原生 dialog 閱讀。

個人島的角色為原創程序幾何造型：深色上衣、眼鏡、背包、筆電與揮手動作。它是代表角色，沒有使用照片建模或宣稱是使用者的外貌還原。

## 日夜、動態與過場

清晨、中午、夕陽、晚上實際改變背景、海面、太陽位置、光線顏色與強度。晚上啟用窗戶與路燈的發光材質、局部照明及螢火蟲。

人物行走、手腳擺動、角色揮手、鳥群飛行與拍翅、船隻繞行、樹木和水面均有環境動態。更新上限約 30 次／秒，可暫停；這些是視覺動態，不是即時產品資料。

相機過場約 1.35 秒、日夜約 1.1 秒，選單與閱讀框以短暫淡入、位移顯示。快速連點可以中斷目前相機移動，再從現有位置前往下一島；手動拖曳也能接管。移動期間暫隱內容熱點，抵達後再顯示，避免點錯。

減少動態效果時停用環境動態、平滑相機與日夜過場，控制仍可操作。開啟閱讀框、隱藏分頁或場景不可見時停止更新；pagehide 釋放幾何、材質、事件、觀察器與 renderer。

## 網址、閱讀與備援

例如 `/zh-tw/?island=journal&time=night&view=note-date-contracts` 還原島嶼、時段與文章。省略時段代表中午；未知的島嶼或時段回到安全預設。舊 `studio=bookflow&topic=architecture` 連結仍能辨識專案，舊的 `view` 繼續可用。

開啟閱讀框建立 history entry，框內切換更新同一 entry。Escape／關閉返回探索狀態；直接開啟分享網址時移除閱讀參數。切換中英文保留島嶼、時段與閱讀內容。原生 dialog 管理背景 inert 與焦點，關閉後回到觸發控制。讀取區域可鍵盤捲動，觸控保持原生捲動。

站內專案及筆記連結留在閱讀框；外部來源另開分頁，Email 交由郵件程式。分享複製目前網址；Clipboard 不可用時提供可選取的網址欄。

WebGL 初始化失敗或 context loss 時，六島地圖、搜尋、所有內容與閱讀控制仍可用。未啟用 JavaScript 時提供獨立內容頁連結。

## 驗證及限制

`npm run verify` 包含格式、型別、內容契約、單元、建置、SEO、四尺寸瀏覽器與 axe 檢查。實際結果見 [TESTING.md](../TESTING.md)。測試另外驗證日夜的畫面確實不同、自主動態會變動且暫停後像素穩定，以及單指／雙指手勢。

本機證據與截圖位於 `docs/evidence/studio/` 和 `docs/screenshots/studio/`，不代表 CI 或正式部署。V2 效能分數與像素基準不適用於 V3。Three.js 已動態匯入，仍有超過 500 kB 的 chunk 提示，沒有提高警告門檻隱藏成本。手機補測另記錄在 TESTING.md；模擬量測不等同實體裝置。尚未量測實體裝置 GPU、電池、Safari／Firefox、人工讀屏或公開網路效能。

手機使用動態 viewport 高度；橫向短螢幕縮減頂部與底部佔用，選單獨立捲動，相機距離也會配合可見高度調整。直向窄螢幕搜尋欄使用 16px 文字，降低 iOS 小字輸入欄被自動放大的情況。新增回歸驗證七組尺寸切換後的控制邊界與閱讀捲動，沒有把模擬視窗變動宣稱為 iOS 軟鍵盤實測。
