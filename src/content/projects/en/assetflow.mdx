## From equipment register to handover

Spreadsheets and messages make it difficult to track equipment, returns and employee handovers. This personal project connects a Vue 3 and TypeScript workspace to REST APIs, keeping changes and their history together.

1. Search and filter the equipment register to inspect status and assignees.
2. Select available equipment and an active employee in the assignment form; reload the list after submission.
3. Release equipment on return, or require a fault description and create a repair record.
4. Track outstanding devices during offboarding, confirm the actual departure date and close the handover with an audit trail.

<ProjectWorkflow project="assetflow" locale="en" />

## Implementation and tradeoffs

**Frontend state and API feedback.** Pinia holds the session user and derived permissions. A shared API client handles HTTP and CSRF. Assignment forms reuse a Dialog and reload data after success to avoid stale device state. UI permissions guide interaction; the server still enforces authorization.

**Assignment and audit commit together.** The lifecycle service locks the employee and asset inside a transaction, checks current state, and writes the assignment, equipment state and audit event. Audit failure rolls back the operation. Disabling a button alone cannot provide this protection against concurrent users.

**Dates describe different facts.** Planned departure, actual departure and handover completion are separate fields. Closure requires no active assignments and an explicit valid departure date. An early equipment return does not imply that an employee has already left.

## Known limits

A personal implementation for one company workspace, with no public login or live demo. Multi-tenancy, SSO and production monitoring are outside its scope. Historical CI does not certify production capacity, physical phones or full accessibility compliance. The repository was confirmed Public on 2026-11-04.
