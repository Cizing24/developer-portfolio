## 從清單到交接的操作成果

設備清冊、領還與離職交接若分散在訊息與試算表，難以確認設備去向。這個個人實作以 Vue 3、TypeScript 與 REST API 串起管理介面，讓異動與歷史紀錄一起保存。

1. 在設備清單搜尋、篩選狀態，查看設備與使用者。
2. 領用表單選擇可借設備與在職員工，送出後重新載入清單。
3. 正常歸還釋放設備；故障歸還需填寫描述並建立維修。
4. 離職交接追蹤未歸還設備，確認實際離職日期後結案，保留稽核紀錄。

## 核心實作與工程取捨

**前端狀態與 API 回饋。** Pinia 保存登入者與權限衍生狀態；頁面透過共用 API client 處理 HTTP 與 CSRF。領還表單沿用共用 Dialog，送出成功後重新讀取資料，避免畫面保留舊的設備狀態。前端權限用於操作提示，真正授權仍由後端執行。

**領用與稽核一起成功。** 生命週期服務在交易內鎖定員工與設備，檢查狀態後寫入領用、設備狀態與 audit；稽核失敗時整筆回滾。這比只在前端停用按鈕更能保護多人操作，但仍須以資料庫測試確認競態。

**日期與時間各自有意義。** 預計離職日、實際離職日與交接完成時間分開保存。完成交接要求零有效領用，並驗證實際日期；不因提早歸還設備就推定員工已離職。
